## Bug Fixes

### sign-in and limits on AI imports, safe recipe HTML, rule gaps

**Commit**: [`223f204`](../../commit/223f204845f5e7f798ace9a477d910824e179125)  
**Author**: Austin Santos  

- extractRecipeFromUrl and parseRecipeFromOCR require a Firebase ID token;
  processRecipeText already did. All three: 25 AI calls per user per day
  (aiUsage, server-only), input caps, max_tokens, maxInstances 5, internal
  errors no longer returned to the caller.
- URL import only fetches public http(s) pages: private, loopback and
  metadata addresses are refused after DNS lookup and on every redirect;
  pages over 3 MB are refused.
- CORS limited to the app's own origins.
- Client sends the ID token and calls the configured project's functions;
  sign-in details are no longer logged.
